# Task 2 – Real Estate Housing Price Prediction

Predict median house values using the California Housing Dataset.

This project implements and compares Ordinary Least Squares (OLS), Ridge (L2), and Lasso (L1) Regression models.

### Key Concepts

* Exploratory Data Analysis
* Missing Value Imputation
* Feature Engineering
* Correlation Analysis
* Multicollinearity
* Standardization
* GridSearchCV
* Model Evaluation using MAE, RMSE, and R²
* Actual vs Predicted Visualization
* Residual Error Analysis
